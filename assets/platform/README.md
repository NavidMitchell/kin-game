# Compact modular platforms — five level palettes

Use one common scale for deck pieces. With the roughly 230px solid deck height displayed at 26 game pixels, two complete end caps occupy approximately 90 game pixels. Existing 120px platforms therefore fit without reducing deck thickness. This is an artwork sizing estimate; collision bounds and exact landing-line alignment remain the coding session's responsibility.

Repeat complete middles for long platforms. For a short or partial middle, take half the required width from each end of middle.webp, joining the two crops at the center. This preserves both cap connections. Do not simply crop one end and attach it to the opposite cap. For lengths below ~90px at this deck thickness, further cap cropping or a smaller common scale is necessary.

The preview shows two caps alone, a 120px target assembly, and three complete middle repeats. All previews are enlarged for inspection, not shown at their actual game size.
